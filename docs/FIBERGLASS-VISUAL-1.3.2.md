## Root causes

1. A Divi Text module is a block. The converter emitted `margin:auto` for centered alignment without preserving default block width. Elementor flex widgets then sized short captions to their contents. In the previous local output, Bermuda's bar measured 228.36px beside a 541.44px image at 1920px. Source CSS treats the Text module as full width. This is a mapped-property/default-semantics defect; an unknown-attribute warning could not identify it.
2. Divi Section base CSS paints white even when a saved custom background color is disabled. Elementor containers are transparent by default. The original second section specifies `background_enable_color="off"` and no active color, so destination page/theme gray showed through. Source `.et_pb_section` defaults and computed white surfaces were confirmed in the public original.
3. Center/left/right module alignment is horizontal. The old all-side shorthand could also reset authored top/bottom spacing. The mapping now changes left/right margins only, with enough specificity to outrank Elementor's flex defaults.
4. Elementor reuses `background_color` for its first gradient stop and solid surface. Divi keeps them independent. Alpha gradients now retain the source/default solid base separately, while source hover colors remain effective. Explicit transparent/color backgrounds override defaults; rows and columns do not acquire Section-only defaults.
5. The Best Pools header/footer, footer service-area cities and third-party chat overlays are absent from this page-only export. Those parts are rendered by sitewide Theme Builder/plugin configuration on the original and destination. The converter cannot reproduce omitted data. New page reports explain this as information and direct users to the separate Headers & Footers workflow/UAE display rules.
6. The supplied report used Open Sans source defaults. The public original's computed styles use **Barlow** headings and **Source Sans 3** body/caption text. Their Theme Customizer definitions are not in this page JSON. Source defaults must be confirmed during mapping; entering a source URL for link lookup does not import all inherited theme styles. QA also renders a separately configured preview with body Source Sans 3, heading Barlow, body size 16px and weight 400. This explicit profile is not claimed as automatic extraction.

## Implementation

TextConverter seeds 100% module width before SizingTranslator; explicit desktop/tablet/mobile/zero widths still win and caps remain separate. SectionConverter seeds native classic white before background translation; active source colors/images/gradients override it. ScopedCssTranslator emits horizontal margins without replacing vertical ones. BackgroundTranslator carries validated independent gradient surfaces and hover colors in portable scoped CSS. BatchRunner/WarningReport disclose page export scope without creating actionable warnings or blocking Apply. Styles survive native template ID changes, direct Apply and saved Apply. Destination page backgrounds, custom CSS, template assignments and unrelated content remain protected.
