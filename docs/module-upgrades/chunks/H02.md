## Module-specific work

### D4-01 — Accordion

Current status: **PARTIAL**. Priority: P1_CORE. Source: [official reference](https://help.elegantthemes.com/en/articles/8611169-the-divi-accordion-module). Source version: Divi 4.

Proposed target: **Legacy Accordion or verified Nested Accordion, chosen by actual content**.

Confirmed current source tags: `et_pb_accordion`.

Required fixture cases: nested modules, mixed title levels, non-first open item, per-item styles, icon variants.

Additional module prerequisites: Common chunk prerequisites.

- [ ] **D4-01.01:** Design a nested output path rather than dropping child modules into unsupported text controls.
- [ ] **D4-01.02:** Preserve item-specific styles/title tags and validated initial state; keep legacy path unchanged.
- [ ] **D4-01.03:** Validate nested editor save/duplicate/import, keyboard focus and mobile behavior.

Acceptance beyond the common contract:

- [ ] Unsupported nesting remains protected until the new path passes.
- [ ] No duplicated FAQ metadata and no destroyed existing native accordion output.

Limits / protected behavior: Not all Divi open/tag/icon combinations match one target widget.

### D4-38 — Tabs

Current status: **PARTIAL**. Priority: P1_CORE. Source: [official reference](https://help.elegantthemes.com/en/articles/8650239-the-divi-tabs-module). Source version: Divi 4.

Proposed target: **Legacy Tabs or verified Nested Tabs**.

Confirmed current source tags: `et_pb_tabs`.

Required fixture cases: nested content, orientations, per-tab states and tablet-to-accordion transition.

Additional module prerequisites: Common chunk prerequisites.

- [ ] **D4-38.01:** Capture actual child structure and preserve tab order/content and separate per-tab styles.
- [ ] **D4-38.02:** Add a nested serialization adapter only for available target features; keep simple repeaters compatible.
- [ ] **D4-38.03:** Test active state, breakpoint mode, keyboard/touch and unique IDs after import.

Acceptance beyond the common contract:

- [ ] Hidden tab content remains reachable and editable.
- [ ] Missing nested feature never creates invalid JSON.

Limits / protected behavior: Current mapper accepts simple tab text without child modules.

### D4-41 — Toggle

Current status: **PARTIAL**. Priority: P1_CORE. Source: [official reference](https://help.elegantthemes.com/en/articles/8650242-the-divi-toggle-module). Source version: Divi 4.

Proposed target: **Legacy Toggle or one-item Nested Accordion where semantically equivalent**.

Confirmed current source tags: `et_pb_toggle`.

Required fixture cases: open/closed default, nested content, per-state icons/styles and long content.

Additional module prerequisites: Common chunk prerequisites.

- [ ] **D4-41.01:** Model independent toggle state distinctly from one-open accordion groups.
- [ ] **D4-41.02:** Preserve per-state title/content/icon settings from real fixtures.
- [ ] **D4-41.03:** Gate any nested adapter on actual controls and test collapse/expand focus and mobile content.

Acceptance beyond the common contract:

- [ ] Several independent toggles can remain open if source permits.
- [ ] Source initial state is not replaced by a target default.

Limits / protected behavior: Current basic toggle mapper is not full arbitrary style/state fidelity.
