Current status: **PARTIAL**. Priority: P1_CORE. Source: [official reference](https://help.elegantthemes.com/en/articles/8616758-the-divi-bar-counters-module). Source version: Divi 4.

Proposed target: **Repeated Progress Bar widgets**.

Confirmed source tags from actual Divi 4.8.2/4.8.1 export: `et_pb_counters`, `et_pb_counter`. See [mapping](../P05-MAPPING.md) and [QA](../../MODULE-UPGRADE-P05-QA.md).

Required fixture cases: parent with multiple bars, 0/100 percentages, custom colors and device typography.

Additional module prerequisites: Common chunk prerequisites.

- [ ] **D4-03.01:** Parse bar children in order with stable element IDs, labels and validated numeric values.
- [ ] **D4-03.02:** Map track, fill, percent display and per-item spacing to their actual widget controls.

Limits / protected behavior: Verified finite decimal 0 through 100 values. Native default geometry/timing remain adaptations; unaccepted critical track/surface states stay protected.

### D4-08 — Circle Counter

Current status: **PARTIAL**. Priority: P1_CORE. Source: [official reference](https://help.elegantthemes.com/en/articles/8617719-the-divi-circle-counter-module). Source version: Divi 4.

Proposed target: **Editable circular-progress adapter; existing numeric Counter retained as explicit approximation**.

Confirmed current source tags: `et_pb_circle_counter`.

Required fixture cases: zero/half/full values, percent on/off, ring thickness/background, responsive sizes.

Additional module prerequisites: Common chunk prerequisites.

- [ ] **D4-08.01:** Add a real circular rendering/control model instead of marking the numeric substitute as visual parity.
- [ ] **D4-08.02:** Preserve the central number/title and captured ring geometry and animation.
- [ ] **D4-08.03:** Keep the existing approximation selectable and report its difference; test required runtime dependency.

Acceptance beyond the common contract:

- [ ] No clipping at 320px or inaccessible color-only value presentation.

Limits / protected behavior: No suitable built-in Free circular counter is assumed.
