## Chunk tasks

- [ ] **H03.01:** Select at most three adapter changes from this chunk; H03 is an audit/shared-translator gate, not authorization to rewrite every listed converter together.
- [ ] **H03.02:** Complete each selected module's tasks and source-to-target mapping specification; flag any missing external data or unmet dependency.
- [ ] **H03.03:** Run its focused positive/negative and editor/frontend tests, then the common acceptance gate before advertising support.
- [ ] **H03.04:** Audit source-style precedence per surface: fonts/loading, four-side responsive padding, borders/shadows, explicit zeros, inherited link decoration, negative margins and disabled hover/transform flags.
- [ ] **H03.05:** Reproduce reported header stacking/overflow with ancestor stacking contexts before changing z-index; do not add arbitrary global z-index fixes.
- [ ] **H03.06:** Define how source-breakpoint supplemental CSS stays consistent after Elementor edits; test editable control values versus compiled source CSS and disclose any reconversion requirement.
- [ ] **H03.07:** Cover unresolved global definitions/presets, supported dynamic links, unsupported ACF/Woo bindings, sticky behavior, patterns/masks and animation with evidence-first mapping or explicit protected limits.
